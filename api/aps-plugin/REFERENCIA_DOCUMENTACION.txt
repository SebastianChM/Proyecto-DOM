========================================
CLASES REVIT API UTILIZADAS
========================================

1. PDFExportOptions (usada en Command.cs)
   Namespace: Autodesk.Revit.DB
   
   Propiedades principales:
   - FileName: Nombre del archivo PDF de salida
   - Combine: Si true, combina todas las laminas en un solo PDF
   - StopOnError: Detener en caso de error
   - ExportQuality: Calidad de exportacion (PDFExportQualityType.PdfHigh)
   - AlwaysUseRasterizer: Usar rasterizacion

2. ExportPDFSettings
   Namespace: Autodesk.Revit.DB
   
   Metodos principales:
   - Create(): Crea nuevo elemento de configuracion
   - FindByName(): Busca configuracion por nombre
   - GetOptions(): Obtiene copia de opciones de exportacion
   - SetOptions(): Establece opciones de exportacion
   - GetActivePredefinedSettings(): Obtiene configuracion activa
   - ListNames(): Lista nombres de configuraciones

========================================
REQUISITOS DE COMPILACION
========================================

1. Visual Studio 2022 Community (gratuito)
   - Workload: ".NET desktop development"

2. Referencias DLL de Revit 2024
   - RevitAPI.dll (C:\Program Files\Autodesk\Revit 2024\)
   - RevitAPIUI.dll (C:\Program Files\Autodesk\Revit 2024\)

3. NuGet Package
   - Autodesk.Forge.DesignAutomation.Revit v2024.0.2

========================================
FLUJO DE DESIGN AUTOMATION
========================================

1. Compilar plugin -> RevitToPdf.dll
2. Empaquetar en estructura .bundle con PackageContents.xml
3. Comprimir a RevitToPdfApp.zip
4. Subir AppBundle a APS via API
5. Crear Activity que vincule el AppBundle
6. Enviar WorkItems para procesar archivos RVT
7. Descargar PDFs generados desde OSS

========================================
NOTAS IMPORTANTES
========================================

- La exportacion a PDF directa esta disponible desde Revit 2022+
- El plugin corre en servidores headless de Autodesk (sin UI)
- Por eso se usa IExternalDBApplication en lugar de IExternalApplication
- No se puede usar RevitAPIUI.dll para funciones de UI
